# BACAR.AZ

Next.js 14 + Tailwind + Prisma + NextAuth demo layihəsi.

## Lokal işə salmaq

```bash
npm install
npm run dev
```

Sayt: `http://localhost:3000` (əgər port doludursa Next avtomatik başqa porta keçə bilər).

## Yoxlama

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Environment

Nümunə üçün `.env.example` faylına bax.
